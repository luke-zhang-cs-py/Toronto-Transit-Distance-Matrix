Toronto Transit Reachbrowser build

Classic OpenStreetMap tiles, no API key. Click anywhere on the map: every stop you can reach is shaded by how long it takes, over the full TTC + YRT + MiWay network. The search runs in your browser.
This is the browser-only build. There is no server: the whole graph is inlined in the page and the reachability search — a port of the same Dijkstra in routing.py — runs in JavaScript. Every wait is therefore modelled (half the typical headway for the mode running the line), not measured: GTFS-realtime needs a backend to fetch it, so live waits and service closures are not in this build, and neither is trip planning.
